## 课程描述

本课程是人工智能技术应用专业的专业必修课。课程讲授 Python 的基础语法和常用库，培养编程思维和解决问题的能力：学生能独立编写简单程序，理解并运用基本的数据结构和算法，掌握调试、错误处理、文件操作等常用技巧，并通过团队编程项目培养协作与沟通能力，为后续的机器学习、数据分析、开发框架、计算机视觉、语音技术等课程打下编程基础。

## 学习目标

学完本课程，学生应能够：

1. 说出 Python 程序的基本组成，正确使用变量、数据类型、运算符和常用内置函数；
2. 用分支和循环结构描述解决问题的步骤，会画简单的流程图；
3. 用字符串、列表、元组、字典、集合组织和处理数据；
4. 定义和调用函数，使用模块、标准库和第三方库组织程序；
5. 读写文本、CSV、JSON 文件，读懂报错信息，用异常处理和调试工具排查错误；
6. 看懂并编写简单的类，用 pandas、Matplotlib 完成简单的数据汇总和画图；
7. 会用 jieba 分词，能调用大模型接口完成简单任务，与同学合作完成一个小型项目；
8. 正确使用 AI 编程助手，遵守个人信息保护等法律法规和学术诚信要求。

## 考核方式

| 部分 | 占比 | 内容 |
|---|---|---|
| 过程性考核 | 50% | 线上学习进度、各章课后练习、实验报告（每章至少完成 2 个 ★ 实验）、第 12 章团队项目 |
| 期末考试 | 50% | 闭卷上机，题型为单选、多选、判断、读程序与简答、编程题，可参考两套[模拟卷](mock-exam.md) |

## 与其他课程的关系

本课程是全专业唯一专门讲 Python 语法的课程，其他教材需要用到 Python 知识时，链接到本书的相应小节。

| 课程 | 关系 |
|---|---|
| 人工智能导论 | 并行。导论讲 AI 的概念，本课程提供动手实现的工具 |
| 人工智能数据分析与处理 | 后续。本书第 11 章只入门 NumPy、pandas、Matplotlib，数据清洗与分析的进阶内容由该课程讲授 |
| 机器学习 | 后续。本书 10.6 节、12.2 节体验了 scikit-learn 的“创建、训练、预测”写法 |
| 人工智能开发框架技术、计算机视觉、自然语言处理、语音技术等 | 后续。都以本课程的 Python 基础为前提 |
