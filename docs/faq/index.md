## 课程与学习方法 { #faq-1 }

??? question "书上标着“待实测”的实验是什么意思？"

    这些实验需要 GPU、下载模型或调用大模型 API，编者的编写环境无法运行，所以没有给出运行结果，而是附了一张记录表，请你运行后自己填写。详见[附录 C](../appendix/a-environment.md)。

## 实验环境与排错 { #faq-2 }

??? question "没有显卡能做实验吗？"

    能。每个实验都有只用 CPU 的小数据版本；需要显卡的部分写明了推荐的云算力平台。详见[附录 C](../appendix/a-environment.md)。
