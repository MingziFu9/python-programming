## 这本书讲什么

Python 是人工智能领域使用最广的编程语言，本专业后续的机器学习、数据分析、深度学习、计算机视觉、自然语言处理等课程，写代码用的都是它。这门课是全专业唯一专门讲 Python 语法的课程，从零开始，不要求任何编程基础。

全书围绕一家虚构的社区小店“街坊便利店”展开：老板陈姐不断提出新需求，店员小周用 Python 一个个解决。从第 1 章打印开业海报，到收银计算、会员管理、销售记录存档、批量整理文件、生成 Excel 日报，再到第 11 章用 pandas 分析全年 8437 条销售记录、画出经营图表，最后在第 12 章分析顾客评价、调用大模型写经营小结，并以小组合作完成“小店管理助手”综合项目。

前 9 章讲 Python 的基础语法：变量与运算、字符串、条件判断、循环、列表、字典、函数、文件与异常；第 10 章学会使用模块、第三方库并初识类与对象；第 11、12 章初步接触数据处理和人工智能应用，为后续课程打基础。

## 本书的特点

- **零基础友好**：用小店里的事讲编程，每个概念先举例再总结；重点难点配交互动画，可以一步一步看程序怎样运行、变量怎样变化；
- **每章动手实验**：★ 为基础实验，☆ 为拓展实验，全部给出完整代码、运行结果、实验记录表和常见问题排查；网页上很多代码块可以点“▶ 试一试”直接在浏览器中运行；
- **结果真实**：书中的运行结果都是编者实际运行得到的；编写环境无法运行的部分标为“待实测”，并提供记录表；
- **在线练习**：每章课后的单选、多选和判断题可以在网页上直接作答，并查看解析；
- **对接证书考试**：对应“信息技术水平-人工智能（Python）”证书，考点按全国计算机等级考试二级 Python 大纲逐条对照（见[证书考点对照](certificate.md)），附两套闭卷[模拟卷](mock-exam.md)；
- **会用也会防**：教你用 AI 助手学编程、查错误，也提醒你核对 AI 的结果、保护个人信息。
