## 教学说明

**学习目标**

1. 能用“模具和产品”的比喻说出类与对象的关系（理解）；
2. 能说出创建对象时 `__init__` 自动执行、`self` 指向新对象（理解）；
3. 能预测调用某个对象的方法后，哪个对象的哪个属性会变化（应用）。

**画面与操作**

- 左边是类 Goods 的代码和创建对象的表单；右边是已创建的对象，每个对象显示自己的三个属性；黑框记录每一步对应的 Python 代码。
- 点对象上的 `.sell(1)` 卖出一件、`.set_price(0.9)` 打九折，只有被点的对象会变化（浅黄色）。

**数据来源**：动画逻辑与教材中 Goods 类的代码一致（JavaScript 模拟）。

**课堂用法建议**

1. 让学生创建 cola、egg 两个对象，先预测“cola.sell(1) 之后 egg.stock 变不变”，再验证。
2. 用同一个变量名再创建一次，讨论“变量名重新贴到新对象上”与第 2 章“变量是标签”的联系。
