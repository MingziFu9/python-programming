类与对象：一个模具压出多个商品

左边的类 Goods 是“模具”，规定每个商品有哪些属性、会做哪些事。填好名称、单价、库存，点“创建对象”，就用模具压出一个商品对象。每个对象有自己的属性值；点对象上的按钮调用它的方法，只有这个对象会变化。
类（模具） 
class Goods:
    def __init__(self, name, price, stock):
        self.name = name
        self.price = price
        self.stock = stock

    def sell(self, qty):
        if qty > self.stock:
            return False
        self.stock -= qty
        return True

    def set_price(self, rate):
        self.price = round(self.price * rate, 2)
