## 教学说明

**学习目标**

1. 能说出调用函数时程序的执行顺序：跳进函数、执行、带着返回值回来（理解）；
2. 能区分局部变量和全局变量，说出函数返回后局部变量的去向（理解）；
3. 能描述递归调用一层层展开、再一层层返回的过程（理解）。

**画面与操作**

- 左边是代码，橙色是下一步要执行的行；右边上方是变量表，“全局”是主程序的变量，调用函数时下面会多出一块该函数的局部变量（递归时会叠好几块）。
- 三个标签分别演示：同一个函数调用两次、同名的局部变量和全局变量互不影响、递归计算 3 的阶乘。

**数据来源**：三段程序都由 `tools/make_trace.py` 在 Python 3.14 中真实运行生成。

**课堂用法建议**

1. 在“调用两次 discount”第 9 行暂停，让学生说出下一步会执行哪一行（第 2 行，而不是第 10 行）。
2. 在“递归”里数一数最多同时有几层 fact()，并说出每一层 n 的值。
