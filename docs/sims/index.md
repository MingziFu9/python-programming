# 交互动画

这些动画都是普通网页，不需要安装任何软件，也不需要联网调用接口，在电脑和手机浏览器上都能打开。每个动画都嵌在对应章节的正文里，也可以从这里单独打开，适合课堂演示。

<!-- sims:start -->
| 章 | 动画 | 你可以做什么 |
|---|---|---|
| 第 1 章 | [程序是怎么运行的](run-program/index.md) | 一行一行执行代码，观察变量和输出怎样变化，以及出错时程序在哪里停下 |
| 第 2 章 | [变量：给数据贴标签](variable-labels/index.md) | 单步执行赋值语句，看变量的值怎样变化，理解“赋值不是相等”“变量不会自动重算” |
| 第 3 章 | [字符串切片尺](slice-ruler/index.md) | 拖动起点、终点、步长三个滑块，看切片取出哪些字符，理解“终点不取”和负数索引 |
| 第 4 章 | [分支流程走一遍](branch-flow/index.md) | 单步执行 if-else 和 if-elif-else 程序，输入不同的值，看程序走了哪条路、跳过了哪些分支 |
| 第 5 章 | [循环追踪：变量一步步变化](loop-trace/index.md) | 单步执行 for 循环、while 循环和 break、continue，观察每一圈变量的变化，理解累加器、计数器和找最大值 |
| 第 6 章 | [列表操作台](list-console/index.md) | 点按钮对列表做 append、insert、pop、remove、del、sort、reverse 等操作，看列表和索引怎样变化，并看到对应的 Python 代码和报错 |
| 第 7 章 | [词频统计：一词一词计出来](word-count/index.md) | 单步执行词频统计程序，观察字典如何随着每个词增加或累加，对比 d[键] 和 d.get(键, 默认值) 的区别 |
| 第 8 章 | [函数调用与返回](function-call/index.md) | 单步执行函数调用，观察参数如何传入、局部变量如何出现和消失、return 如何带回结果，以及递归调用时一层层叠起来的调用 |
