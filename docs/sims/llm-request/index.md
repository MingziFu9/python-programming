## 教学说明

**学习目标**

1. 能说出一次大模型接口调用中请求和回复各包含哪些部分（API Key、model、messages；状态码、choices、usage）（理解）；
2. 能写出从回复中取出文字的路径 `result["choices"][0]["message"]["content"]`（应用）；
3. 能根据状态码 401 和 ConnectionError 判断出错原因（分析）。

**画面与操作**

- 左边填写密钥、模型和问题，可以切换“服务器没启动”；右边依次显示请求、回复和取出的内容。
- 按“下一步”逐步观察；“试试”中的按钮可以一键体验密钥为空、服务器没启动两种出错情况。

**数据来源**：回复的格式和文字与配套的模拟服务器 `labs/ch12/mock_llm_server.py` 一致，编者已用实验 12-2 的程序实际运行核对。真实大模型服务（如 DeepSeek）的回复格式相同，但文字由模型生成，每次可能不同。

**课堂用法建议**

1. 先让学生在纸上写出“取出回复文字”的路径，再按到第 3 步核对。
2. 清空 API Key 后再发送，讨论“为什么密钥不能写在代码里、不能截图外传”。
3. 对比 400、401、404 等常见状态码的含义（见 12.3 节表格）。
