## 教学说明

**学习目标**

1. 能说出 for 循环每一圈循环变量取什么值、循环体执行几次（理解）；
2. 能手工画出累加、找最大值程序的变量追踪表（应用）；
3. 能区分 continue（跳过本圈）和 break（结束整个循环）（理解）。

**画面与操作**

- 左边是代码，橙色是下一步要执行的行；右边上方是变量表，刚变化的变量用浅黄色标出；右下是输出。
- “累加 1～4”演示累加器；“找最高营业额”演示 while、计数器和找最大值（输入 1280、1890、1406）；“continue 与 break”演示跳过和提前结束。

**数据来源**：三段程序都由 `tools/make_trace.py` 在 Python 3.14 中真实运行生成。

**课堂用法建议**

1. 先让学生在纸上画追踪表（每一圈 i 和 total 的值），再用动画核对。
2. 在“找最高营业额”中问：如果删掉 `count += 1`，会发生什么？
