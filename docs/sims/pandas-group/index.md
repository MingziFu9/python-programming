## 教学说明

**学习目标**

1. 能说出 `df[条件].groupby(列)["金额"].sum()` 这一行代码依次做的三件事（理解）；
2. 能预测筛选后剩下哪几行、分成几组（应用）；
3. 能区分 sum、count、mean 三种汇总的结果（理解）。

**画面与操作**

- 左上选择筛选条件、分组列、汇总方式，下方显示对应的 pandas 代码；每按一次“下一步”，代码中正在执行的那一段变成黄色。
- 第 ① 步不符合条件的行被划掉；第 ② 步同一组的行涂成同一种颜色，下方列出每组的金额；第 ③ 步显示 print 的输出。

**数据来源**：表格是配套数据 `labs/data/sales_2025.csv` 的前 14 行（虚构）。全部 45 种组合的输出都由编者用 pandas 3.1 实际运行生成后写入动画，和你在电脑上运行的结果一致。

**课堂用法建议**

1. 选“金额 >= 10、按品类、sum”，先让学生在纸上圈出留下的行、算出每组合计，再点“下一步”核对。
2. 同一筛选条件下切换 sum、count、mean，讨论“计数”和“求和”的区别。
3. 选“支付方式 == 微信”再“按支付方式”分组，讨论为什么只剩一组。
