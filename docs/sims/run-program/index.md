## 教学说明

**学习目标**

1. 能说出 Python 解释器从上到下、一行一行执行程序（理解）；
2. 能指出程序出错时停在哪一行，后面的代码不会执行（理解）。

**画面与操作**

- 左边是代码，橙色的行是“下一步要执行的行”，绿色的行是“刚刚执行完的行”。
- 右上是此刻的变量，刚发生变化的变量用浅黄色标出；右下是程序到目前为止的输出。
- 点“下一步”执行一行；“自动播放”每 0.9 秒执行一行；上方的两个按钮切换两段程序。

**数据来源**：两段程序都由 `tools/make_trace.py` 真实运行生成，变量和输出与在 Python 3.12 中运行的结果一致。第一段程序中 `input` 的输入假设为“小周”。

**课堂用法建议**

1. 先让学生只看代码，猜一猜输出是什么，再用“下一步”验证。
2. 在“出错的程序”里，问学生：为什么第 5 行的文字没有显示出来？引出“程序遇到错误就停止”。
