## 教学说明

**学习目标**

1. 能说出正向索引和反向索引的编号方式（记忆）；
2. 能写出取前几个、后几个、中间一段、倒序的切片表达式（应用）。

**画面与操作**

- 每个字上方的蓝色数字是正向索引，下方的橙色数字是反向索引。
- 三个滑块分别控制起点、终点、步长；勾选“留空”表示该位置不写。被取出的字用蓝色背景标出，底部有橙色下划线的是第一个被取的字。
- 下方的按钮给出了常用写法，点一下就能看到效果。

**数据来源**：切片结果在浏览器中按 Python 的切片规则计算。编者用 Python 3.14 核对过下列结果：`s = "街坊便利店欢迎您"` 时，`s[0:4]` 为“街坊便利”，`s[-3:]` 为“欢迎您”，`s[::2]` 为“街便店迎”，`s[::-1]` 为“您迎欢店利便坊街”，`s[1:6:2]` 为“坊利欢”。

**课堂用法建议**

1. 先出题：“取出手机号的后 4 位怎么写？”让学生在纸上写，再用动画验证。
2. 让学生把步长调成 -1，再把起点、终点调来调去，总结“结果为空”的规律。
