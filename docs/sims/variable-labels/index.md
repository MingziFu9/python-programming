## 教学说明

**学习目标**

1. 理解赋值语句“先算右边，再贴到左边的名字上”（理解）；
2. 能预测变量重新赋值后，其他变量是否跟着变化（应用）。

**画面与操作**

- 左边是代码，橙色是下一步要执行的行；右边上方是变量表，刚变化的变量用浅黄色标出；右下是输出。
- “改价格”演示改了 `price` 以后 `total` 不会自动重算；“计数与交换”演示 `count = count + 1`、`+=` 和一步交换两个变量。

**数据来源**：两段程序都由 `tools/make_trace.py` 在 Python 3.14 中真实运行生成。

**课堂用法建议**

1. 执行到“改价格”第 5 行时暂停，让学生举手投票：第 6 行打印的 total 是 7.0 还是 8.0？
2. 让学生说出 `count = count + 1` 在数学里为什么“不成立”，在 Python 里为什么可以。
