## 教学说明

**学习目标**

1. 能说出 `counts[w] = counts.get(w, 0) + 1` 在“第一次见到”和“再次见到”一个词时分别做了什么（理解）；
2. 能区分 `d[键]` 和 `d.get(键, 默认值)` 在键不存在时的不同表现（理解）。

**画面与操作**

- 左边是代码，橙色是下一步要执行的行；右边上方是变量表，刚变化的变量用浅黄色标出，可以看到字典 counts 一步步变长；右下是输出。
- “词频统计”演示核心一行；“取值、新增与修改”演示字典的增改查，最后一步故意用不存在的键，看 KeyError。

**数据来源**：两段程序都由 `tools/make_trace.py` 在 Python 3.14 中真实运行生成。

**课堂用法建议**

1. 在第 6 行暂停，让学生说出 `counts.get(w, 0)` 这一次会得到几，再点“下一步”验证。
2. 让学生把第 6 行改写成 if-else 的形式（`if w in counts: ... else: ...`），比较哪种更简洁。
