# 1.1 程序和编程语言

## 1.1.1 程序就是写给电脑的菜谱

- 菜谱：一条一条的步骤，按顺序做
- 程序：写给电脑的一条条**指令**
- 写程序的过程叫**编程**
- 写程序用的语言叫**编程语言**

::: notes
做一道番茄炒蛋，菜谱会这样写：
菜谱有三个特点：步骤是一条一条的；要按顺序做；每一步都要写清楚，不能写“适当处理一下”。
程序（Program）就是写给电脑的菜谱：一条一条的指令，告诉电脑先做什么、再做什么。手机上的微信、收银台的收银系统、导航软件，都是程序。和人不同，电脑非常“死板”：它不会猜你的意思，指令写错一个符号，它就做不下去。所以写程序最重要的习惯是：写清楚，写准确。
写程序的过程叫编程（Programming）。编程的人要用电脑能看懂的“话”来写指令，这种“话”就是编程语言（Programming Language）。
:::

## 1.1.2 解释器：一行一行地执行

- 电脑只认识 0 和 1
- **解释器**把 Python 代码逐行翻译并执行
- 像同声传译：翻一句、做一句
- 遇到错误就停下来报错

!sim run-program

::: notes
电脑的芯片其实只认识 0 和 1。我们用 Python 写的程序，是怎么变成电脑能执行的动作的呢？中间有一个“翻译”，叫解释器（Interpreter）。安装 Python，主要就是在电脑上装好这个解释器。
解释器的工作方式很像同声传译：从程序的第一行开始，翻译一行、执行一行，再翻译下一行……直到最后一行。如果某一行出了错，它就在那一行停下来，报告错误，后面的代码都不会执行。
下面的动画演示了这个过程。点“下一步”，看解释器每执行一行，右边的变量和输出发生了什么变化；再切换到“出错的程序”，看程序在哪一行停下来。
动画里出现的 `print`、`input`、变量，本章和下一章都会详细讲。现在只要记住一点：程序从上往下，一行一行地执行；出错就停。
:::

## 1.1.3 编程语言有很多种

- C：写操作系统、单片机，速度快
- Java：写大型网站、安卓应用
- JavaScript：写网页
- Python：数据分析、人工智能的首选

::: notes
和人类有汉语、英语一样，编程语言也有很多种：C 语言常用来写操作系统和单片机程序，Java 常用来写大型企业系统，JavaScript 是网页的语言，Python 则在数据分析和人工智能领域用得最多。不同的语言“语法”不同，但核心思想相通：变量、判断、循环、函数……学会一门，再学别的就快多了。
:::

- 1989 年由吉多·范罗苏姆开始设计

- **写得短**，同样的功能代码更少

## 1.2.2 Python 与人工智能

- 大模型、人脸识别背后大量用 Python
- 飞桨、昇思、PyTorch 都以 Python 为主

::: notes

# 1.5 交互模式与脚本文件

## 1.5.1 Shell：问一句答一句

- `>>>` 后输入一行，回车立即看到结果
- 输入算式不写 print 也会显示
- 适合试一个写法、算一个数

::: notes
Thonny 下方的 Shell 有一个提示符 `>>>`，在它后面直接输入代码，按回车，马上就能看到结果。这种方式叫交互模式（Interactive Mode），就像和电脑一问一答：
在交互模式下，直接输入算式，不用 `print` 也会显示结果。交互模式适合试一试：忘了某个写法，在这里敲一下就知道。缺点是关掉就没了，没法保存。
:::

## 1.5.2 脚本文件：保存起来反复运行

## 1.5.3 缩进和代码规范

- 行首空格有意义，不能随便加
- PEP 8：逗号后加空格
- 运算符两边各加一个空格
- `#` 后面加一个空格

::: notes
Python 对每行开头的空格非常敏感。行首的空格叫缩进（Indentation），在 Python 里缩进是有含义的（第 4 章讲 `if` 时会用到），不能随便加。现阶段请记住：每一行代码都从最左边顶格开始写。
除了必须遵守的语法，Python 社区还有一份大家约定俗成的写法建议，叫 PEP 8。 现阶段记住三条就够：
不遵守 PEP 8 程序也能运行，但遵守了别人读起来更舒服。Thonny 和 AI 编程助手写出来的代码基本都符合这个规范。
:::

## 1.6.3 三种最常见的报错

- SyntaxError 在运行前就会被发现
- NameError、IndentationError 最常见

::: notes
语法错误（Syntax Error）比较特别：解释器在运行之前会先把整个程序检查一遍，发现语法错误就直接报告，一行都不运行。而 `NameError` 这类错误是运行到那一行才发现的，前面的行已经执行过了。
:::

## 1.6.3 三种最常见的报错

| 错误类型 | 中文意思 | 最常见的原因 | 例子 |
|---|---|---|---|
| `SyntaxError` | 语法错误 | 括号、引号不成对；用了中文标点；少了冒号 | `print("合计", 1288` 少了右括号 |
| `NameError` | 名字错误 | 变量名、函数名拼错；变量还没赋值就用了；文字忘了加引号 | `print(shop_nmae)`、`prnit("你好")` |
