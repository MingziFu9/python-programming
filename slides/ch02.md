# 2.1 变量：给数据贴标签

## 2.1.1 赋值语句

- 变量：给数据贴一张**标签**
- `price = 3.5` 是**赋值语句**
- 执行顺序：**先算右边，再贴到左边**
- `=` 不是“等于”，是“贴标签”

::: notes
程序在运行过程中要记住很多数据：单价、数量、总价……给数据起一个名字，以后用名字就能找到它，这个名字就叫变量（Variable）。
`price = 3.5` 这样的语句叫赋值语句（Assignment Statement）。这里的等号 `=` 不是数学里的“等于”，而是“把右边的值存起来，贴上左边的名字”。可以把变量想象成一张标签：数据放在电脑内存里，变量名是贴在数据上的标签，通过标签就能找到数据。
赋值语句的执行顺序是：先算右边，再贴到左边。所以第 3 行先算 `price * qty`，也就是 3.5 × 2 = 7.0，再把 7.0 贴上 `total` 这个标签。
:::

## 2.1.2 变量可以重新赋值

- 标签可以撕下来贴到新数据上
- 旧数据不受影响
- `count = count + 1`：先算右边再贴回去

# 2.2 数字：整数与浮点数

## 2.2.1 两种数字

- **整数** int：`2`、`-5`、`2025`
- **浮点数** float：`3.5`、`0.9`
- 整数和浮点数一起算，结果是浮点数

::: notes
Python 里的数字主要有两种：
整数和浮点数一起运算，结果是浮点数，所以 `3.5 * 2` 的结果是 `7.0` 而不是 `7`。
:::

## 2.2.2 0.1 + 0.2 为什么不等于 0.3

- `0.1 + 0.2` 得到 `0.30000000000000004`
- 浮点数在电脑里是近似值
- 显示时保留两位小数即可

::: notes
在 Shell 里试一下：
这不是 Python 的错误。电脑内部用二进制保存小数，就像十进制写不尽 1/3（0.3333……）一样，二进制也写不尽 0.1，只能保存一个非常接近的近似值，于是计算结果在小数点后很多位出现了一点误差。 几乎所有编程语言都有这个现象。
对收银这类场景，处理办法很简单：显示时保留两位小数（2.6 节），比较时先四舍五入。真正对精度要求很高的财务系统会使用专门的 `decimal` 模块，本书不展开。
:::

## 2.2.3 round：四舍五入

- `round(3.14159, 2)` → `3.14`
- `round(2.5)` → 2，`round(3.5)` → 4
- 恰好一半时取偶数

::: notes
`round(数字, 位数)` 把数字保留指定位数的小数：
注意最后一行：`round(2.5)` 得到 2，`round(3.5)` 得到 4。Python 的 `round` 遇到“正好一半”时，会取偶数那一边，这叫“银行家舍入”，目的是让大量数据舍入后的总误差更小。收银时如果一定要“逢五进一”，可以用 2.6 节的格式化显示。
:::

# 2.3 字符串、布尔值与 None

## 2.3.1 字符串

- 引号括起来的文字
- `"3" + "5"` 得到 `"35"`，不是 8
- 手机号、编号用字符串存

::: notes
第 1 章已经见过字符串：用引号括起来的文字，类型名是 `str`。字符串可以用 `+` 连接、用 `*` 重复：
`"3" + "5"` 得到的是 `"35"` 而不是 8，因为它们是文字，不是数。字符串的更多用法见第 3 章。
:::

## 2.3.2 布尔值

- 只有 `True` 和 `False`
- 比较的结果就是布尔值：`3 > 2` → True

::: notes
有些问题的答案只有“是”和“不是”：今天是不是周末？顾客是不是会员？金额是不是超过 100 元？表示“真”和“假”的数据叫布尔值（Boolean，类型名 `bool`），只有两个：`True` 和 `False`，首字母必须大写。
比较运算（`>`、`==` 等）的结果就是布尔值。布尔值是第 4 章“条件判断”的基础。
:::

## 2.3.3 None：什么都没有

- `None` 表示“没有值”
- 例：还没填会员号

::: notes
`None` 是一个特殊的值，表示“没有值”“空”。例如顾客没有会员号，可以写 `member_id = None`。它的类型是 `NoneType`。初学阶段知道它表示“空”就行，第 8 章讲函数时还会遇到它。
:::

- `type(3.5)` → `<class 'float'>`

不确定一个数据是什么类型，就用 `type()` 问一问：

## 2.3.4 用 type 查看类型

| 类型 | 类型名 | 例子 | 用途 |
|---|---|---|---|
| 整数 | `int` | `2`、`-5`、`2025` | 数量、年份、个数 |
| 浮点数 | `float` | `3.5`、`0.9`、`1e3` | 价格、重量、温度 |

# 2.4 运算符

## 2.4.1 算术运算符

- `/` 结果总是浮点数：`10 / 5` → `2.0`
- `//` 取商，`%` 取余数
- 除数为 0：`ZeroDivisionError`

::: notes
两个要注意的地方：
除数为 0 时会报 `ZeroDivisionError: division by zero`（除以零错误），第 1 章动画里的“出错的程序”就是这个错误。
:::

## 2.4.1 算术运算符

| 运算符 | 含义 | 例子 | 结果 |
|---|---|---|---|
| `+` | 加 | `3 + 2` | `5` |
| `-` | 减 | `3 - 2` | `1` |
| `*` | 乘 | `3 * 2` | `6` |
| `/` | 除 | `7 / 2` | `3.5` |
| `//` | 整除（只要商的整数部分） | `7 // 2` | `3` |
| `%` | 取余数 | `7 % 2` | `1` |
| `**` | 乘方 | `2 ** 10` | `1024` |

## 2.4.2 运算顺序

- 先乘方，再乘除，后加减
- 拿不准就加括号

::: notes
和数学一样，先乘方，再乘除，后加减；同级的从左往右算；有括号先算括号里的：
拿不准的时候就加括号，既保证正确，也方便别人看懂。实验 2-3 的月供公式就加了很多括号。
:::

## 2.4.3 复合赋值运算符

- `count += 1` 等于 `count = count + 1`

::: notes
`count = count + 1` 太常用了，Python 提供了简写：
这些叫复合赋值运算符（Augmented Assignment Operator）。注意 Python 没有其他语言里的 `x++` 写法。
:::

## 2.4.3 复合赋值运算符

| 简写 | 等价于 | 例子（设 `x = 5`） |
|---|---|---|
| `x += 3` | `x = x + 3` | `x` 变成 8 |
| `x -= 3` | `x = x - 3` | `x` 变成 2 |
| `x *= 2` | `x = x * 2` | `x` 变成 10 |
| `x /= 2` | `x = x / 2` | `x` 变成 2.5 |

# 2.5 类型转换与 input

## 2.5.1 input 得到的永远是字符串

- 输入 2，得到的是 `"2"`
- `"2" * 3` 得到 `"222"`
- 要做计算，必须先转换

::: notes
回到情景导入的问题。`input` 不管你输入什么，交给程序的都是字符串。输入 `2`，得到的是 `"2"`：
`"2" * 3` 是把文字“2”重复 3 次，于是得到 222。而 `"3.5" * "2"` 两段文字相乘就更没有意义了，所以报 `TypeError`（类型错误）。
:::

## 2.5.2 int、float、str 转换

- `float(input("单价："))`：先输入，再转换
- **ValueError**：内容不对；**TypeError**：类型不对

::: notes
解决办法是类型转换（Type Conversion）：用 `int()` 把字符串转成整数，`float()` 转成浮点数，`str()` 把数字转成字符串。
`float(input("单价："))` 是两个函数“套”在一起：先执行里面的 `input`，拿到字符串 `"3.5"`，再交给外面的 `float`，转成浮点数 3.5。
几个转换的例子和常见错误：
`ValueError`（值错误）是“类型对了但内容不对”，`TypeError`（类型错误）是“类型就不对”。两者都是初学者天天会遇到的报错。
:::

## 2.5.2 int、float、str 转换

| 写法 | 结果 | 说明 |
|---|---|---|
| `int("3.5")` | `ValueError: invalid literal for int() with base 10: '3.5'` | 带小数点的字符串不能直接转整数，先 `float` 再 `int` |
| `int("两个")` | `ValueError` | 不是数字的文字不能转 |
| `"合计" + 7` | `TypeError: can only concatenate str (not "int") to str` | 字符串只能和字符串连接，要写 `"合计" + str(7)` |

## 2.5.3 eval：把字符串当代码算（慎用）

- `eval("1 + 2 * 3")` → 7
- 能计算输入的表达式
- 会执行任何代码，有安全风险
- 数字输入优先用 int、float

::: notes
还有一个函数 `eval()`，它会把字符串当成 Python 表达式来计算：
有人会写 `x = eval(input("请输入："))`，这样输入整数、小数都能自动识别。但这样做有风险：如果输入的不是数字，而是一段恶意代码，`eval` 也会照样执行。所以本书不推荐用 `eval` 处理用户输入，转换数字请用 `int` 和 `float`。计算机二级考试中常见 `eval(input())` 的写法，能看懂即可。
:::

# 2.6 f-string 格式化输出

## 2.6.1 在字符串里插入变量

- 字符串前加 `f`，变量写在花括号里
- `f"单价 {price} 元"`

::: notes
小票上要显示“单价 3.50 元 × 2”。用逗号或 `+` 拼起来很麻烦，还要处理小数位数。Python 提供了更方便的写法 f-string（格式化字符串）：在引号前加一个字母 `f`，字符串里用花括号 `{}` 放变量或算式，运行时会自动替换成它的值。
:::

## 2.6.2 格式说明

- 冒号后面是格式：`{x:.2f}`

::: notes
花括号里冒号后面的部分叫“格式说明”，控制显示的样子。最常用的几种：
`.2f` 里的 `f` 是“浮点数”的意思，和字符串前面的 `f` 不是一回事。`.2f` 显示时会四舍五入，但不会改变变量本身的值。
以前的教材里还能看到 `"%.2f" % x` 和 `"".format(x)` 两种老写法，作用和 f-string 一样，能看懂即可，自己写代码用 f-string。
:::

## 2.6.2 格式说明

| 写法 | 含义 | 例子 | 结果 |
|---|---|---|---|
| `{x:.2f}` | 保留 2 位小数 | `f"{3.14159:.2f}"` | `3.14` |
| `{x:,.2f}` | 千分位逗号 + 2 位小数 | `f"{1234567.891:,.2f}"` | `1,234,567.89` |
| `{x:.1%}` | 百分比，1 位小数 | `f"{0.256:.1%}"` | `25.6%` |
| `{x:>6}` | 占 6 格，靠右对齐 | `f"{'可乐':>6}"` | `    可乐` |
| `{x:<6}` | 占 6 格，靠左对齐 | `f"{'可乐':<6}"` | `可乐    ` |
| `{x:05d}` | 整数占 5 位，前面补 0 | `f"{42:05d}"` | `00042` |

## 2.7 前沿视窗：报错越来越友好

- Python 每年 10 月发布新版本
- 报错会提示 `Did you mean ...?`
- 3.14 的交互模式自动给代码上色
- 语言设计者也在降低入门门槛

::: notes
Python 每年 10 月发布一个新版本，近几年一个重要的改进方向是让报错信息更友好。第 1 章看到的 `Did you mean: 'shop_name'?` 就是 3.10 以后才有的。本书使用的 Python 3.14（2025 年 10 月发布）进一步改进：把保留字打错了，它也能猜出来。
3.14 的交互模式还会给代码自动上色，并能在 `import` 后面按 Tab 键补全模块名。2026 年 10 月发布的 Python 3.15 则把默认的文件编码统一为 UTF-8， 以后在 Windows 上读写中文文件出乱码的情况会少很多（第 3、9 章会讲编码）。
这些变化说明，编程语言的设计者也在努力降低入门门槛。但无论报错多友好，读懂报错仍然是程序员的基本功。
:::
