## 情景导入

- 陈姐要办会员卡，整理登记的信息
- 去掉多余空格，统一格式
- 小票上的手机号要隐藏中间四位
- 处理的都是**文字**：字符串

::: notes
陈姐想给老顾客办会员卡，让小周把登记表录进电脑。登记表是顾客自己填的，五花八门：有人把手机号写成“138 0013 8000”，有人写成“138-0013-8000”；有人名字前面多空了一格；地址里“幸福路”有的写成“幸福路 ”，有的写成“幸福 路”。
陈姐还提了个要求：“小票上印手机号，中间四位要打星号，现在都讲究保护个人信息。”小周在网上见过别人做的会员系统，打出来的小票上是“1388000”，可这是怎么做到的呢？
这些工作的共同点是：处理的都是文字。电脑擅长算数，处理文字同样拿手。这一章，我们深入学习字符串：怎样取出其中一段，怎样去掉多余的空格、替换文字、拆开和拼接，以及为什么用 Excel 打开一个文件会冒出一堆“锟斤拷”式的乱码。
:::

# 3.1 字符串的写法

## 3.1.1 单引号、双引号和三引号

- 单引号、双引号都可以，前后一致
- 文字里有单引号，外面就用双引号
- 三引号：跨越多行的文字

::: notes
字符串可以用单引号或双引号括起来，两者完全一样。如果文字里本身有引号，就用另一种引号括起来：
要写跨越多行的文字，用三个引号（`"""` 或 `'''`）括起来，换行会原样保留：
:::

## 3.1.2 转义字符

- 反斜杠开头：`\n` 换行，`\t` 制表
- Windows 路径的 `\` 容易出问题
- 写成 `\\`，或用原始字符串 `r"..."`

::: notes
有些字符没法直接打出来，比如“换行”。Python 用反斜杠 `\` 加一个字母来表示，这叫转义字符（Escape Character）：
Windows 的文件路径里有很多反斜杠，很容易“误伤”。比如 `print("C:\new\table")` 里的 `\n` 被当成换行、`\t` 被当成 Tab，结果变成：
有两种解决办法：把每个 `\` 写成 `\\`，或者在引号前加字母 `r`，写成 `r"C:\new\table"`。加了 `r` 的叫原始字符串（Raw String），里面的反斜杠不再转义。第 9 章读写文件时会经常用到。
:::

## 3.1.2 转义字符

| 转义字符 | 含义 | 例子 | 显示效果 |
|---|---|---|---|
| `\n` | 换行 | `"第一行\n第二行"` | 分成两行显示 |
| `\t` | 制表符（Tab，跳到下一个对齐位置） | `"姓名\t电话"` | `姓名	电话` |
| `\\` | 反斜杠本身 | `"C:\\new\\table"` | `C:\new\table` |
| `\"`、`\'` | 引号本身 | `"他说：\"好\""` | `他说："好"` |

# 3.2 索引与切片

## 3.2.1 索引：从 0 开始数

- 第一个字符的**索引**是 0
- -1 是最后一个，-2 是倒数第二个
- `len(s)` 求长度

::: notes
字符串里的每个字符都有一个编号，叫索引（Index）。Python 的索引从 0 开始：第 1 个字符的索引是 0，第 2 个是 1……用“字符串[索引]”就能取出某个字符。
索引也可以是负数，表示从后往前数：-1 是最后一个，-2 是倒数第二个。以 `s = "街坊便利店欢迎您"` 为例：
`len()` 返回字符串的长度，也就是有多少个字符。一个汉字、一个字母、一个空格、一个标点都算 1 个字符。长度为 8 的字符串，最大索引是 7，写 `s[8]` 就会报错 `IndexError: string index out of range`（索引超出范围）。
:::

## 3.2.1 索引：从 0 开始数

| 字符 | 街 | 坊 | 便 | 利 | 店 | 欢 | 迎 | 您 |
|---|---|---|---|---|---|---|---|---|
| 正向索引 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
| 反向索引 | -8 | -7 | -6 | -5 | -4 | -3 | -2 | -1 |

## 3.2.2 切片：取出一段

- `s[起:止]`：**含头不含尾**
- `s[:4]` 前 4 个，`s[-4:]` 后 4 个
- `s[::2]` 隔一个取一个，`s[::-1]` 倒过来
- 超出范围不报错

!sim slice-ruler

::: notes
取出连续的一段用切片（Slicing），写法是 `字符串[起点:终点]`，取出从起点开始、到终点之前为止的字符，即“含起点，不含终点”：
“不含终点”有一个好处：`s[:4]` 正好取出 4 个字符，`s[4:]` 正好是剩下的，两者拼起来就是原字符串，不重不漏。
切片还可以加第三个数——步长，写成 `[起点:终点:步长]`，表示每隔几个取一个。步长为负数时从后往前取，`[::-1]` 是把字符串倒过来的常用写法：
下面的动画是一把“切片尺”，拖动滑块，看看每种写法取出了哪几个字。
切片的几个实用写法：
切片超出范围不会报错，只会取到能取的部分，例如 `"abc"[1:100]` 得到 `'bc'`；这一点和索引不同。
:::

## 3.2.2 切片：取出一段

| 需求 | 写法 | `phone = "13800138000"` 时的结果 |
|---|---|---|
| 前 3 位 | `phone[:3]` | `'138'` |
| 后 4 位 | `phone[-4:]` | `'8000'` |
| 去掉第一位 | `phone[1:]` | `'3800138000'` |
| 第 4～7 位 | `phone[3:7]` | `'0013'` |
| 手机号脱敏 | `phone[:3] + "****" + phone[-4:]` | `'138****8000'` |

## 3.2.3 字符串不能修改

- `s[0] = "A"` 报 TypeError
- 要“改”，就拼出一个新字符串
- 手机号脱敏：`p[:3] + "****" + p[-4:]`

::: notes
字符串一旦创建，里面的字符就不能修改，这叫“不可变”（Immutable）：
要“修改”字符串，实际做法是生成一个新字符串，再赋值给变量，例如 `s = "x" + s[1:]`。下面要讲的 `replace`、`upper` 等方法也是这样：它们都不改原字符串，而是返回一个新的。
:::

# 3.3 字符串的常用方法

## 3.3.1 什么是方法

- 方法：属于某种数据的函数
- 写法：`数据.方法()`
- `x.upper()` 返回新字符串，x 不变

::: notes
除了 `len()` 这样的函数，字符串还自带很多“技能”，叫方法”调用的函数")（Method）。调用方法的写法是“字符串.方法名(参数)”，中间有一个点：
注意 `x` 没有变，`upper()` 返回了一个新字符串，存到了 `y` 里。如果想让 `x` 变成大写，要写 `x = x.upper()`。初学者常犯的错误是只写 `x.upper()` 却不赋值，结果发现 `x` 没变。
:::

## 3.3.2 去空格：strip

- 去掉两端的空格和换行
- 中间的空格不去

::: notes
这里在前后加上方括号，是为了看清空格在哪里。录入数据时，先 strip 一下是好习惯。`strip` 只去两头，中间的空格要用下面的 `replace`。
:::

## 3.3.2 去空格：strip

| 方法 | 作用 |
|---|---|
| `s.strip()` | 去掉两头的空格（也包括换行、Tab） |
| `s.lstrip()` | 只去掉左边（开头）的 |
| `s.rstrip()` | 只去掉右边（结尾）的 |

## 3.3.3 替换：replace

- `s.replace(旧, 新)` 替换所有
- 方法可以连着写：`s.strip().replace(...)`

::: notes
`s.replace(旧, 新)` 把所有的“旧”换成“新”：
第三行把三个方法连着写：先 `strip`，在结果上再 `replace` 两次。因为每个方法都返回一个新字符串，所以可以一直“点”下去。把“新”写成空字符串 `""`，就相当于删除。
:::

## 3.3.4 拆分与拼接：split 和 join

- `"a,b,c".split(",")` → `['a', 'b', 'c']`
- `"、".join(列表)` 用连接符拼起来
- 处理表格数据时非常常用

::: notes
`s.split(分隔符)` 按分隔符把字符串拆开，得到一个列表（用方括号括起来的一组数据，第 6 章详细讲）。不写分隔符时，按空格（连续的空格、换行都算）拆：
`join` 正好相反，用一个连接符把一组字符串连起来，写法是“连接符.join(一组字符串)”：
`split` 和 `join` 在处理表格数据时非常常用：表格的一行“矿泉水,2.0,91”按逗号一拆，就得到了三个格子的内容。第 9 章读 CSV 文件时会用到。
:::

## 3.3.5 查找与计数

- `in` 判断是否包含

::: notes
`in` 不是方法，而是一个运算符，读起来像英语：“便利 在 街坊便利店 里吗？”它的结果是布尔值，下一章写判断条件时经常用到。
:::

## 3.3.5 查找与计数

| 方法或写法 | 作用 | 例子 | 结果 |
|---|---|---|---|
| `s.find(子串)` | 找子串第一次出现的位置，找不到返回 -1 | `"街坊便利店".find("便利")` | `2` |
| `s.index(子串)` | 同上，但找不到时报错 `ValueError` | `"街坊便利店".index("超市")` | 报错 |
| `s.count(子串)` | 统计子串出现几次 | `"好吃好吃".count("好")` | `2` |
| `s.startswith(x)` | 是否以 x 开头 | `"D00012".startswith("D")` | `True` |
| `s.endswith(x)` | 是否以 x 结尾 | `"photo.jpg".endswith(".jpg")` | `True` |
| `x in s` | s 里是否包含 x | `"便利" in "街坊便利店"` | `True` |
| `x not in s` | s 里是否不包含 x | `"超市" not in "街坊便利店"` | `True` |

## 3.3.6 大小写转换

- `upper()` 大写，`lower()` 小写
- 只对英文字母起作用
- 比较前统一：`ans.lower() == "yes"`

::: notes
`upper()` 转大写、`lower()` 转小写，只对英文字母起作用：
用户输入英文时大小写不统一（`Yes`、`YES`、`yes`），先统一转成小写再比较，就不会漏掉。身份证号末位的 `x` 也常用 `upper()` 统一成大写 `X`。
:::

## 3.4 长度与判断方法

- `isdigit()` 判断是不是全是数字
- `"12.5".isdigit()` 是 False

::: notes
`len()` 前面已经用过。字符串还有一组以 `is` 开头的方法，用来检查内容，结果都是布尔值：
注意 `"12.5".isdigit()` 是 `False`，因为小数点不是数字字符。检查手机号时，可以组合起来：长度是 11、全是数字、以 1 开头，三个条件都满足才算格式正确。怎样把三个条件“组合”起来？下一章学习。
:::

## 3.4 长度与判断方法

| 方法 | 检查什么 | 例子 | 结果 |
|---|---|---|---|
| `s.isdigit()` | 是否全是数字字符 | `"123".isdigit()`、`"12.5".isdigit()` | `True`、`False` |
| `s.isalpha()` | 是否全是字母（含汉字） | `"可乐".isalpha()` | `True` |
| `s.isalnum()` | 是否全是字母或数字 | `"abc123".isalnum()` | `True` |
| `s.isupper()` / `s.islower()` | 字母是否全大写 / 全小写 | `"ABC".isupper()` | `True` |

# 3.5 格式化进阶

## 3.5.1 对齐与填充

- `f"{x:>6}"` 右对齐，`f"{x:<6}"` 左对齐
- `"7".zfill(3)` → `"007"`
- 生成单号：`"D" + str(12).zfill(5)`

::: notes
2.6 节学过 f-string 的对齐写法。字符串还有几个现成的方法：
`zfill` 适合生成单号：`"D" + str(12).zfill(5)` 得到 `D00012`。
:::

## 3.5.2 中文对齐的小麻烦

- 一个汉字在屏幕上约占两格
- 中英文混排时对不齐
- 办法：用全角空格补位，或接受不完美

::: notes
用 f-string 对齐中英文混合的内容时，会发现对不齐：
两个都是占 6 格，但屏幕上一个汉字通常占两个字母的宽度，所以中文那一格看起来更宽。打印小票时，可以把中文内容放在每行最后，或者用 Tab（`\t`）分隔，避免这个问题。这是所有编程语言处理中文时都会遇到的小麻烦，不必深究。
:::

# 3.6 中文与编码初识

## 3.6.1 字符在电脑里是数字

- 电脑只能存数字
- **Unicode** 给每个字符一个编号
- `ord("街")`、`chr(65)` 互相转换

::: notes
电脑只能保存数字。每个字符都有一个对应的编号，Python 的 `ord()` 函数可以查到编号，`chr()` 反过来由编号得到字符：
这套全世界统一的编号叫 Unicode，它给世界上几乎所有文字的每个字符都分配了一个编号，“中”是 20013。 Python 3 的字符串就是一串 Unicode 字符，所以处理中文和处理英文一样方便。
:::

## 3.6.2 编码：把字符存成文件

- 编码：把字符变成字节
- **UTF-8**：国际通用，汉字占 3 个字节
- GBK：老的中文编码，汉字占 2 个字节

::: notes
字符串要保存到文件、在网络上传输时，还要把编号换成一个个字节（电脑存储的基本单位）。把字符变成字节的规则叫字符编码（Character Encoding）。中文环境最常见的两种：
字符串的 `encode()` 方法按指定编码变成字节，`decode()` 反过来：
`b'...'` 表示这是字节，`\xe8` 这样的写法是一个字节的十六进制数。看不懂没关系，要看懂的是：同样两个字，两种编码存出来的字节完全不同。
:::

## 3.6.2 编码：把字符存成文件

| 编码 | 特点 | 一个汉字占几个字节 |
|---|---|---|
| [**UTF-8**](../../appendix/glossary.md#g-UTF-8 "最常用的 Unicode 编码方式，英文占 1 字节，常用汉字占 3 字节"){ .term } | 国际通用，网页、Linux、手机、Python 的默认编码 | 3 |
| **GBK** | 中文 Windows 的传统编码，老的 Excel、记事本常用 | 2 |

## 3.6.3 乱码是怎么来的

- 用 A 编码存，用 B 编码读，就是乱码
- “街坊”变成了“琛楀潑”
- 读写文件时写清楚 `encoding="utf-8"`

::: notes
用 A 编码存的文件，却用 B 编码去读，就会出现乱码。比如按 UTF-8 存的“街坊”，被当成 GBK 来读：
“街坊”变成了“琛楀潑”。这就是乱码的本质：文字没丢，只是“翻译”用错了字典。最常见的场景是：Python 程序按 UTF-8 保存了一个表格文件，在中文 Windows 上用老版本 Excel 双击打开，Excel 按 GBK 去读，满屏乱码。解决办法在第 9 章：保存时用 `utf-8-sig` 编码，Excel 就能认出来。
:::

## 3.7 前沿视窗：大模型眼中的文字

- 大模型按**词元**处理文字，不按字符
- 一个汉字可能是一个或几个词元
- 按词元计费，数字数常常数不准

::: notes
我们用 `len()` 数的是“字符”。大模型（如 DeepSeek、通义千问）读文字时，用的却是另一种单位，叫 词元（Token）。模型会先把一句话切成一个个词元，再把每个词元换成一个编号去计算。一个词元可能是一个汉字、半个汉字，也可能是一个常见的词；英文里常见单词通常是一个词元，生僻长词会被切成几段。
这件事和我们有两个关系：
把一段文字切成词元的过程，叫分词。中文分词还有一个常用的 Python 工具 jieba，第 12 章会用它统计顾客评价里的高频词。
:::
