## 学习目标

- **说出**函数的定义、调用、参数、返回值
- **解释** return 与 print 的区别
- **使用** def 定义带参数和返回值的函数
- **使用** assert 测试自己写的函数
- **分析**递归函数的执行过程

## 情景导入

- 收银程序 200 多行，折扣代码复制了三遍
- 陈姐改规则，小周要改三处，还漏改一处
- 问题出在“复制粘贴”
- 打包起来、起个名字、随叫随用：**函数**

::: notes
小周的收银程序已经有 200 多行了。陈姐让他加一个“退货”功能、一个“会员日”功能，小周一看，这两个功能都要算折扣，于是把收银那段“满 100 减 15、会员 9.5 折”的代码复制了两份过去。
一个月后，陈姐说：“下个月改成满 100 减 20。”小周改了收银里的那一处，忘了另外两处。月底对账，退货金额和收银金额对不上，查了一晚上才找到原因。
问题出在“复制粘贴”。同样的代码出现在好几个地方，改一处就要改所有地方，漏一处就出错。更好的办法是：把“算折扣”这段代码打包起来，起个名字叫 `discount`，哪里要用就“叫一声”这个名字。规则变了，只改这一个地方。
这个“打包起来、起个名字、随叫随用”的东西，就是函数。其实我们早就在用函数了：`print`、`input`、`len`、`round` 都是 Python 写好的函数。这一章，我们学习自己写函数。
:::

# 8.1 定义和调用函数

## 8.1.1 def：定义一个函数

- `def 函数名(参数):`，末尾有冒号
- 函数体缩进 4 个空格
- 调用：`函数名(值)`
- 先定义，后调用

::: notes
用 `def`（define，定义）关键字定义一个函数：
第 1～2 行是定义函数：`def` 后面是函数名 `greet`，括号里的 `name` 是参数，表示调用时要“传进来”的数据；冒号后面缩进的部分是函数体。
第 4～5 行是调用函数：写函数名加括号，括号里给出具体的值。调用时，“小周”被传给 name，然后执行函数体。
函数的命名规则和变量一样（2.1.3 节），最好用动词或动词短语说明它“做什么”，如 `discount`（打折）、`mask_phone`（手机号脱敏）、`print_receipt`（打印小票）。
:::

## 8.1.2 为什么要用函数

- **复用**：写一次，到处调用
- **好改**：规则变了只改一处
- **好读**：`pay = discount(total)` 一看就懂
- **好分工**：大程序拆成小函数

# 8.2 参数

## 8.2.1 位置参数

- 多个参数用逗号隔开
- 按位置一一对应：`add(3, 5)`
- 少传参数报 TypeError

::: notes
函数可以有多个参数，用逗号隔开。调用时，值按位置一一对应地传给参数，叫位置参数：
3 传给 a，5 传给 b。给的值多了或少了都会报错，而且报错信息很清楚：
第一个的意思是“add() 缺少 1 个必需的位置参数 b”，第二个是“add() 需要 2 个位置参数，却给了 3 个”。
:::

## 8.2.2 默认值与关键字参数

- `def discount(total, rate=0.95):`
- 调用时可省略有默认值的参数
- 关键字参数：`discount(total=128, rate=0.9)`
- 有默认值的参数放在后面

::: notes
定义时可以给参数一个默认值，调用时不给这个参数，就用默认值：
调用时写成 `参数名=值` 的形式，叫关键字参数。它有两个好处：可以跳过中间有默认值的参数（第 3 行）；可以不管顺序（第 4 行），而且一看就知道每个值是什么意思。
两条规则：定义时，有默认值的参数要放在后面，写成 `def f(a=1, b):` 会报 `SyntaxError: parameter without a default follows parameter with a default`；调用时，关键字参数要放在位置参数后面。
:::

# 8.3 返回值

## 8.3.1 return：把结果带回来

- return 结束函数，把值交给调用处
- 没有 return，返回 None

!sim function-call

::: notes
`return` 的作用是结束函数，并把一个值带回调用的地方。这个值叫返回值：
`add(3, 5)` 这个调用，执行完就“变成”了 8，所以可以赋值给变量，也可以放进表达式里，甚至可以作为另一个函数的参数（`add(add(1, 2), 3)`）。
执行到 return，函数立即结束，return 后面的代码不再执行。没有写 return，或者 return 后面什么都不写，函数返回 `None`。

## 8.3.2 return 与 print 的区别

- print 只是显示在屏幕上
- return 才能把结果交给程序继续用
- 函数负责计算用 return，显示交给主程序

::: notes
这是初学者最容易混淆的地方。看两个函数：
`add2` 把 8 显示在了屏幕上，但并没有把它交回来，所以 r 得到的是 None。打个比方：return 是把算好的账单交到你手上，你可以拿去用；print 是把账单念一遍给你听，听完手里什么也没有。
经验是：函数负责计算，用 return 交出结果；要不要显示、怎么显示，交给调用它的人决定。这样的函数可以用在更多地方。
:::

# 8.4 局部变量与全局变量

## 8.4.1 函数里的变量只在函数里有效

- 函数里赋值的变量是**局部变量**
- 同名的外面变量不受影响
- 每个函数各管各的

::: notes
在函数里面赋值的变量（包括参数），叫局部变量，只在这个函数里有效；在函数外面（主程序里）赋值的变量，叫全局变量。
函数里的 x 和外面的 x 同名，但它们是两个不同的变量，函数里改 x 不影响外面。y 是函数的局部变量，函数一结束就消失了，在外面用它报 NameError。
这样设计的好处是：每个函数都有自己独立的“小天地”，写函数时不用担心变量名和别人重名。
:::

## 8.4.2 在函数里使用全局变量

- 函数里可以读全局变量
- 要修改得写 global，否则 UnboundLocalError
- 尽量少用 global：用参数传入、return 带回

::: notes
函数里可以读取全局变量：
但如果要在函数里修改全局变量，直接写会报错：
因为函数里出现了对 count 的赋值，Python 就把它当成局部变量，而这个局部变量还没有值。要修改全局变量，需要先用 `global` 声明：
不过，尽量少用 global。更好的写法是把需要的数据作为参数传进去，把结果用 return 交出来，这样函数之间的关系一目了然。
:::

# 8.6 lambda 与递归入门

## 8.6.1 lambda 与 sorted(key=...)

- `lambda x: x[1]`：没有名字的小函数
- 配合 sorted、max、min 的 key 使用
- 只适合临时用一次的简单函数

::: notes
`sorted`、`max`、`min` 都可以接收一个 `key` 参数，告诉它“按什么来比”。key 的值是一个函数：对每个元素调用这个函数，按函数的返回值排序。
7.2.2 节的词频排序 `key=lambda x: x[1]` 中，`lambda` 是一种只有一行的匿名函数（没有名字的函数），写法是 `lambda 参数: 返回值`。下面两种写法完全等价：
lambda 只适合这种“临时用一下、一行就能写完”的小函数。本书对 lambda 的要求是：看到 `key=lambda x: ...` 能读懂它“按什么排”，会照着写。实验 8-3 用它给商品按销量、价格排序。
:::

## 8.6.2 递归入门

- 函数调用自己，叫**递归**
- `fact(4) = 4 * fact(3)`……一层层往下
- 必须有结束条件，否则 RecursionError

::: notes
函数在自己的函数体里又调用自己，叫递归。经典的例子是阶乘：n! = n × (n-1) × … × 1。换个说法：n 的阶乘 = n × (n-1) 的阶乘，而 1 的阶乘是 1。照着这句话就能写出函数：

另一个经典例子是斐波那契数列（1, 1, 2, 3, 5, 8, …，从第 3 个起，每个数是前两个数之和）：
写递归的两个要点：必须有结束条件；每次调用都要让问题变小，向结束条件靠近。如果忘了结束条件，函数会无限地调用自己，直到 Python 报错：
意思是“超过了最大递归深度”。递归写起来简洁，但不一定快，`fib(40)` 要算很久。本书对递归只要求看懂这两个例子；能用循环解决的问题，初学阶段优先用循环。
