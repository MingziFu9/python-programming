## 12.1.1 让程序“变聪明”的三种办法

| 做法 | 怎么做 | 优点 | 缺点 |
|---|---|---|---|
| 写规则 | 自己写 if：包含“太久”“缺货”“贵”就是差评 | 简单，结果可解释 | 规则写不完，换个说法就认不出 |
| 训练模型（[**机器学习**](../../appendix/glossary.md#g-机器学习 "不靠人写规则，而是让模型从数据中自己总结规律，再用规律对新数据做判断"){ .term }） | 准备一批标好“好评/差评”的评价，让模型自己总结规律 | 不用自己想规则，数据越多越准 | 需要标好的数据，结果可能出错 |

## 12.2.1 jieba 中文分词

- `jieba.lcut(s)` 精确模式
- `cut_all=True` 全模式
- `jieba.add_word("街坊便利店")` 添加新词
- 分词 + 停用词 + 字典计数 = 关键词

::: notes
英文单词之间有空格，用 `split()` 就能拆开；中文的词和词之间没有空格，要靠专门的工具把句子切成一个个词，这叫分词。jieba 是最常用的 Python 中文分词库，用 `pip install jieba` 安装。
`lcut` 返回一个列表。精确模式把句子切成最合理的词，适合做统计；全模式把所有可能成词的组合都列出来，会有重复和“上到”这样的怪词。第一次运行时，jieba 会显示几行“Building prefix dict...”的加载信息，这是正常的。
jieba 不认识的新词（如店名、商品名）可能被切开。用 `add_word` 告诉它：
分好词以后，用第 7 章学过的字典计数，就能找出顾客评价里最常出现的词。统计前要去掉“很”“的”“，”这类没有实际意义的停用词。完整的程序见实验 12-1。
:::

# 12.3 调用大模型接口

## 12.3.1 API、API Key 与 token

- **API**：程序调用服务的约定
- **API Key**：通行证，等于钱包
- 不写进代码、不截图、设消费上限
- 按词元计费

::: notes
大模型的全称是大语言模型（LLM），它们非常庞大，普通电脑运行不了，它们运行在服务商的服务器上。我们的程序通过网络把问题发过去，服务器把模型的回答发回来。程序之间这样约定好格式、互相调用的方式，叫 API（应用程序接口）。
使用之前，要在服务商的开放平台注册账号、实名认证，然后创建一个 API Key，它是一长串字符，相当于你的“通行证”，每次请求都要带上。服务商按使用量收费，计量单位是词元（token）：发过去的问题和收到的回答都要算词元。
发给大模型的问题，也叫提示词（prompt）。提示词写得好不好，直接影响回答的质量。写提示词有几个简单的技巧：
一定要把真实的数据交给大模型，并要求它只根据这些数据写。否则大模型可能会“编造”出看起来很合理、实际不存在的数字。
:::

## 12.3.1 API、API Key 与 token

| 技巧 | 不好的写法 | 好的写法 |
|---|---|---|
| 说明身份和任务 | 写个小结 | 你是一家社区便利店的经营助理，请写本周经营小结 |
| 给出数据 | （不给数据，让它自己编） | 营业额：2446.9 元，订单数：101 单…… |
| 规定格式和长度 | 写详细点 | 不超过 150 字，分“总体情况、亮点、建议”三点 |

| 状态码 | 含义 | 常见原因 |
|---|---|---|
| 200 | 成功 | |
| 400 | 格式错误 | 请求的 JSON 写错了，如缺少 messages |
| 401 | 认证失败 | API Key 写错、过期或没带 |
| 402 | 余额不足 | 账户没钱了 |

| 500、503 | 服务器故障或繁忙 | 服务商的问题，稍后再试 |

## 12.5 编程伦理与法律

- 个人信息保护法：不非法收集、提供
- 发给 AI 前删掉姓名、手机号
- AI 生成内容要标识（2025 年 9 月 1 日起）
- 尊重开源许可，诚信学习

::: notes
会编程，意味着你有能力批量地处理数据、自动地做事情。能力越大，越要守规矩。
1. 保护个人信息
《中华人民共和国个人信息保护法》于 2021 年 11 月 1 日起施行。姓名、手机号、身份证号、住址、消费记录都属于个人信息。和编程有关的几条底线：
2. 标识 AI 生成的内容
国家互联网信息办公室等四部门发布的《人工智能生成合成内容标识办法》自 2025 年 9 月 1 日起施行，要求 AI 服务提供者对生成的文本、图片、音频、视频等内容添加标识。我们自己用 AI 写的周报、文案，对外发布时也应当说明“由 AI 生成”，不能冒充人工撰写，更不能用 AI 编造新闻、伪造他人的声音和图像。实验 12-2 在保存的小结末尾加上了“本内容由人工智能生成，请人工核对后使用”。
3. 尊重知识产权
网上的代码不等于可以随便用。开源代码也有“许可证”，规定了能不能商用、要不要注明出处。使用别人的代码，要遵守许可证，并注明来源。
4. 诚信学习
用 AI 帮忙学习编程是好事，但作业和考试要遵守老师的规定。把 AI 写的代码原样交上去，自己却看不懂，既是不诚信，也学不到本领。等级考试是闭卷上机，靠的还是自己的真本事。
:::

## 12.6 前沿视窗：AI 编程智能体

- 自己读文件、改代码、跑命令
- 智能体 = 大模型 + 一组工具函数
- 你要说清需求、读懂结果、把好安全关

::: notes
第 1 章介绍的 AI 编程助手，主要是“你问它答”：你贴代码，它解释或修改，最终由你复制、运行。2025 年以来，AI 编程工具迅速发展为智能体（Agent）：你用一句话描述任务，它自己去读项目里的文件、修改多个文件、在终端里运行命令和测试，看到报错再接着改，直到完成。
例如阿里云的通义灵码提供了文件查找、文件读取、文件修改、终端执行等十多种工具，供智能体模式调用；Anthropic 的 Claude Code 也能读懂整个项目、编辑文件、运行命令。还记得第 8 章说的吗？智能体本质上就是“大模型 + 一组工具函数”，大模型负责决定下一步调用哪个函数。
这会让编程变得不再需要学习吗？恰恰相反：
学好基础，再用好 AI，你就能用一个人的力量做出过去一个小团队才能做的事。
:::
